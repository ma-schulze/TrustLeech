# Source Artifacts

This folder contains the source code artifacts. 
In general, the following is contained:

- `./docker/`:
    Scripts for the docker environment 
- `./buildroot/`:
    The buildroot toolchain 
- `./arm-trusted-firmware/`:
    A modified version of TF-A supporting the injection of the TrustLeech-hypervisor
- `./trustleech`:
    The source code for the TrustLeech-hypervisor
- `./libvmi`:
    The modified LibVMI version supporting the TrustLeech Backend
- `./vmi_client/`:
    The source code for different client using LibVMI used for the various evaluations
- `./linux/`:
    The Linux kernel, with kernel modules to inject and remove TrustLeech as well as the rootkits used in the evaluation 
- `./qemu-8.0.3`:
    The QEMU version used to evalute the performance of the Legacy KVM Backend of LibVMI. 
    This was extended to enable this Backend for Aarch64 targets.
- `./qemu`:
    The host QEMU version used to run the images generated by buildroot
- `./device-tree/`:
    Modified device trees used for the image 
- `./kvmtool/`:
    The LKVM hypervisor used to spawn VMs in the QEMU environment (not modified)
- `./u-boot/`:
    The u-boot bootloader (not modified)
- `./memdump/`:
    A Python script to evaluate the memory dumps created as part of the evaluation 
- `./overlay/`:
    Files used by buildroot to add to the generated rootfs
